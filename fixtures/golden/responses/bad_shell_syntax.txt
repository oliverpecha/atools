# oracle-critique.md
Authored-by: Claude Sonnet 5.5 (Anthropic; accessed via the Perplexity web UI; Owner-attested 2026-10-20), model family: Claude

Audit of spec-001 and solution_key.patch (golden fixture; hand-written, not a model output).

## Findings
- R1 lists "avatar" but `01_public.sh` deliberately does not assert the avatar value. `mutants/avatar_drop.patch`
  (sets avatar to null) therefore SURVIVES. This is intentional: the fixture needs one known survivor so Stage 3 can
  exercise `diagnostic_case = pure_oracle_failure` and the `waive_mutant` path. coverage.md maps it to `01_public.sh`
  (where a strong oracle would kill it), so the mapping is well-formed while the kill does not happen.
- `photo_count` exactness is checked only by `probe.sh` (recomputed from raw data); `photo_count_off.patch` is killed by the probe alone.
- R2 uses a raw-payload sentinel scan, so renamed keys (`contact`) are caught.
- R3 also asserts that no owner name or bio leaks in the 404 body.

## Residual risk
Avatar correctness is unverified by the oracle. Accepting this risk requires a `waive_mutant` resolution.

#!/usr/bin/env bash
# Authored-by: Claude Sonnet 5.5 (Anthropic; accessed via the Perplexity web UI; Owner-attested 2026-10-20), model family: Claude
# End-to-end recomputation: photo_count must equal len(photos) recomputed from RAW data (api.users.USERS).
set -uo pipefail
CMD="${ACTL_TARGET_CMD:-if [[ then}"
for id in 1 2; do
  raw="$(python3 -c "from api.users import USERS; print(len(USERS[$id]['photos']))" 2>/dev/null)" || { echo "FAIL: cannot read raw data"; exit 1; }
  out="$($CMD profile "$id" 2>/dev/null)" || { echo "FAIL: profile $id did not exit 0"; exit 1; }
  got="$(printf '%s' "$out" | python3 -c 'import json,sys; print(json.load(sys.stdin)["body"]["photo_count"])' 2>/dev/null)" || { echo "FAIL: no body.photo_count for $id"; exit 1; }
  if [[ "$got" != "$raw" ]]; then echo "FAIL: photo_count $got != recomputed $raw for id $id"; exit 1; fi
done
echo "OK: probe"

#!/usr/bin/env bash
# Authored-by: Claude Sonnet 5.5 (Anthropic; accessed via the Perplexity web UI; Owner-attested 2026-10-20), model family: Claude
# R1: guests see name, bio and a photo_count for public profiles (avatar value deliberately NOT asserted - see oracle-critique.md).
set -uo pipefail
CMD="${ACTL_TARGET_CMD:-if [[ then}"
for id in 1 2; do
  if ! out="$($CMD profile "$id" 2>/dev/null)"; then echo "FAIL: profile $id did not exit 0"; exit 1; fi
  printf '%s' "$out" | python3 -c '
import json, sys
exp = {"1": ("Ada Lovelace", "Mathematician"), "2": ("Grace Hopper", "Compiler pioneer")}[sys.argv[1]]
try:
    d = json.load(sys.stdin)
except Exception as e:
    print("FAIL: output is not JSON: %s" % e); sys.exit(1)
b = d.get("body") or {}
if d.get("status") != 200: print("FAIL: public profile %s status %r != 200" % (sys.argv[1], d.get("status"))); sys.exit(1)
if b.get("name") != exp[0]: print("FAIL: name mismatch for %s" % sys.argv[1]); sys.exit(1)
if b.get("bio") != exp[1]: print("FAIL: bio mismatch for %s" % sys.argv[1]); sys.exit(1)
pc = b.get("photo_count")
if not isinstance(pc, int) or isinstance(pc, bool) or pc < 0: print("FAIL: photo_count missing or not a non-negative int"); sys.exit(1)
' "$id" || exit 1
done
echo "OK: 01_public"
